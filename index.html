Hello, I'm Hana

I’m a junior web developer with a background in travel, aviation, and customer service, recently completing a Level 5 Diploma in Web Applications Development with Code Institute.

I build responsive web applications using HTML, CSS, JavaScript, Python, and Django, focusing on clean design, usability, and creating practical solutions through hands-on projects.

During my development journey, I have worked on frontend projects as well as a full-stack Django application using PostgreSQL, APIs, and third-party integrations. I enjoy the problem-solving side of development and turning ideas into functional, user-focused applications.

I’m continuing to strengthen my skills across frontend and backend development while looking for opportunities to grow as part of a collaborative development team.

I believe the best way to learn is by building, experimenting, and continuously improving through real projects.
